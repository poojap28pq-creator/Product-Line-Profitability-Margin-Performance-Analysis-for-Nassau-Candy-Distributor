# 🍫 AI-Assisted Product Line Profitability & Margin Performance Dashboard

## 📌 Project Overview

This project presents an interactive Business Intelligence dashboard developed for Nassau Candy Distributor to analyze:

- Product profitability
- Margin performance
- Division efficiency
- Revenue concentration
- Cost diagnostics
- Margin volatility
- Dependency risks

The dashboard was developed using Python and Streamlit to provide data-driven insights for strategic business decision-making.

---

# 🎯 Objectives

The major objectives of this project are:

- Analyze product-level profitability and margins
- Identify high-profit and low-margin products
- Compare division-level revenue and profit efficiency
- Detect pricing inefficiencies and cost-heavy products
- Perform Pareto analysis for revenue and profit concentration
- Analyze margin volatility and operational risks
- Build an interactive Streamlit dashboard for business intelligence
